# 头像资源文件夹

## 使用说明：

1. 将优香的头像图片放到这个文件夹，命名为：
   - `yuuka.png` (或 yuuka.jpg / yuuka.jpeg)

2. 将你自己的头像图片放到这个文件夹，命名为：
   - `user.png` (或 user.jpg / user.jpeg)

3. **推荐图片规格：**
   - 格式：PNG / JPG / JPEG
   - 尺寸：正方形最佳（如 200x200, 400x400）
   - 大小：< 500KB（加载更快）

4. **放置完成后刷新浏览器即可看到新头像**

## 示例文件结构：

```
assets/
├── yuuka.png      ← 优香的头像（必填）
└── user.png       ← 你的头像（必填，不填则显示默认）
```

## 注意事项：

- 图片名称必须是小写的 `yuuka` 和 `user`
- 支持 png/jpg/jpeg 格式
- 如果找不到图片，会自动回退到 emoji 头像
